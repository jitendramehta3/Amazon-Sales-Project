# Amazon Sales Data Analysis


## 📌 Project Overview



This project focuses on analyzing an Amazon-style sales dataset using Python, SQL, and Power BI.
The main objective of this project is to practice the complete Data Analytics workflow from data cleaning and exploratory analysis to SQL-based analysis and interactive dashboard creation.
The analysis focuses on areas such as Revenue, Cost, Profit, Units Sold, Sales Channel, Region, Item Type, and Order trends.

# 📂 Project Workflow

## 1. Data Cleaning & Preparation — Python
The dataset was explored and prepared using Python.
Key activities included:
* Checking dataset structure and data types
* Handling missing values
* Checking duplicate records
* Converting date columns into proper datetime format
* Analyzing numerical and categorical columns
* Creating calculated metrics such as Profit
* Performing Exploratory Data Analysis (EDA)

## 2. Exploratory Data Analysis — Python
EDA was performed to understand the sales data and identify useful patterns.
Some of the analysis included:
- Total Revenue
- Total Cost
- Total Profit
- Total Units Sold
- Revenue by Region
- Revenue by Item Type
- Sales Channel analysis
- Profit analysis
- Order trends over time

## 3. SQL Analysis
SQL was used to perform business-oriented analysis on the dataset.
Concepts used include:
- SELECT
- WHERE
- GROUP BY
- HAVING
- Aggregate Functions
- CASE WHEN
- Subqueries
- CTEs
- Window Functions
- RANK()
- PARTITION BY
- Top-N analysis

One of the analyses performed was identifying the Top 3 Item Types within each Region using CTEs and the RANK() window function.

## 4. Power BI Dashboard
An interactive Power BI dashboard was created to present the analysis visually.
Dashboard includes:

KPIs

- Total Revenue
- Total Profit
- Total Orders
- Total Units Sold
- Profit Margin

Visualizations:

- Revenue by Item Type
- Revenue by Region
- Revenue Trend Over Time
- Revenue by Sales Channel
- Profit-related analysis
- Sales Channel distribution
- Filters  Slicers
- Region
- Year
- Item Type
- Sales Channel
The dashboard allows users to filter the data and explore different aspects of sales performance.

## 📊 Key Business Metrics
The project analyzes the following major metrics:

| Metric        | Description   |                    


| Revenue       | Total sales generated             |

| Cost          | Total cost associated with sales  |

| Profit        | Revenue minus Cost                |

| Profit Margin | Profit as a percentage of Revenue |

| Units Sold    | Total quantity of products sold   |

| Orders        | Number of orders                  |
